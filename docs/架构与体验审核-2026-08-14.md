# 行迹 TRACE · 架构与用户体验审核报告

> 日期：2026-08-14 · 视角：顶级 App 架构师 + UI 设计专家 + 普通用户三方交叉

## 总评

这是一个**组织得相当清醒的纯前端项目**——四专题页已收敛为「数据驱动引擎」（`topic.html` + 注册表 + `topic-common.js`），纠偏算法收进 `geo.js`，导出独立成 `vault.js`，语音正文/润色输出都正确转义，IndexedDB 还有 localStorage 兜底。**工程兜底意识在，方向都对。**

真正的短板不在「会不会写」，而在三件事上：**① 新手首次成功那条链路没打通**（静默失败 + 入口错位）；**② 令牌/组件/公共逻辑没有收口**（v1→v2 换肤过渡期，三套变量并存、DeepSeek 调用复制 6 份、esc 语义不一致）；**③ 数据体积与加载方式粗放**（3MB 全国 JSON 全量注入）。

下面按「用户会不会撞上」分三档。

---

## P0 · 用户会直接撞上的功能级问题

**1. 网页/浏览器环境语音录音静默失效（真 bug）**

`travel-notes.js:895-902` 里 Web Speech 降级回调调的是 `onVoiceStart()/onVoiceResult()/onVoicePartial()/onVoiceError()`——这四个函数**全项目没有任何定义**（真正的回调是 `window.__tnOnVoiceStart` 等，在 `:908-965`）。异步回调抛 `ReferenceError` 被事件循环吞掉，界面停在 idle。结果：手机浏览器/桌面点麦克风「毫无反应」，且三处说法自相矛盾（代码注释/设置页一个说支持网页降级、一个说不支持）。**要么把 4 个回调改成 `window.__tnOnVoice*` 同一套逻辑，要么网页环境明确禁用并提示「请在 App 内使用」——至少点下去要有反馈。**

**2. 深色模式下地图缩放按钮「真·隐形」**

`node-manager.html:69` 用 `!important` 把 Leaflet 缩放按钮锁死浅米白底，而字色走 `--color-ink-soft`（深色下翻成浅色）→ 浅字浅底。`map.css:170` 的缩放按钮也漏了 `.theme-dark` 覆盖，`wishlist.html` 同样中招。这是当前**唯一「看得见的功能失效」级视觉 bug**，深色下 +/− 号几乎不可见。

**3. 断网时搜索页整页失效，连本地游记都搜不了**

`search.html:78-93` 里 `loaded` 只有在 662KB 的 `nation-index.js` 加载成功后才置 true；`s.onerror` 只改了提示文字没置 loaded，于是 `render()` 里「游记」分组永远不渲染。**本地游记（明明在手机里）应该独立于景点索引**——索引加载失败也要能搜本地。

**4. 首启被 5 步引导连番轰炸**

`index.html:510-546`（tnGuide，2 步，key `tn_guide`，z-index 9900）和 `index.html:584-611`（ob-mask，3 步，key `tn_onboarded`，z-index 9990）**两套引导用不同 key、互不感知**，ob-mask 盖在 tnGuide 上，退掉一层露出另一层，内容还都在讲「语音记录」。合并成一套 3 步即可。

**5. node-manager「生成介绍」默认模型名不一致（真 bug 隐患）**

`node-manager.html:237` 用 `localStorage.getItem('tn_model') || 'deepseek-chat'`，而 `travel-notes.js:29` 明确把 `deepseek-chat` 当作需要映射到 `deepseek-v4-flash` 的旧别名、`travel-notes.js:998-999` 会做映射。node-manager 既没走别名、默认值也和 travel-notes 的 `deepseek-v4-flash` 不一致。**首次用「生成介绍」很可能打到旧模型名报错。**

## P1 · 架构与工程质量

**设计令牌无单一事实源**：`design.css` 里三套变量并存（中文色阶 `:15-55`、英文 `--color-*` `:98-129`、兼容别名 `:131-156`），且 `:1127-1132` 的二次 `:root{}` 把 `--radius-md`(16↔14)、`--fs-*` 静默覆盖。圆角/字号跨组件漂移的直接根源。

**模块级重复仍未收口**（估计还可收敛 300–400 行）：

- DeepSeek 调用复制 **6 处**（`travel-notes.js:994/501/618`、`results.js:20`、`review.html:454`、`node-manager.html:233`）——改端点/模型/流解析要同步 6 处，必漏（第 5 条 bug 就是这么来的）。
- haversine **4 份全量实现**，其中 `review.html:261` 缺 `Math.min(1,·)` 钳制，近对跖点产生 NaN。
- `esc()` 语义不一致：`topic-common.js:20` 和 `travel-map.html:349` **不转义引号**，`travel-notes.js:105` 转义——这是下面 XSS 缺口的根源。

**自定义节点链路有存储型自 XSS 面**：用户节点 `label/desc`（用户输入/DeepSeek 输出）被 merge 进 SITES 后，`topic-common.js:451/540/377` 直接 `innerHTML` 拼接且未转义。单机单用户实际危害低，但属正确性缺陷，统一 `esc`（含引号）后套用即可。

**数据体积与加载**：全国地图 `topic.html?p=nation` 把 3.04MB 的 `nation-data.js` 单个 `window.SITES` 全量注入（6700+ 景点阻塞主线程解析）；同一份数据又以 `nation-index.js`(662KB) 另一种格式冗余一份。`topic-meta.js` 119KB 整包加载（只用到其中 1 条配置）。**改按省懒加载（已有分省 `*-data.js`）可把全国首屏从 ~3.8MB 降到 1MB 内。**

**持久层**：`travel-notes.js:83-95` 每次保存 `clear()` 后 `forEach put` **全量重写整库**——照片以 base64 内嵌，50 篇×多图时单次保存重写数十 MB，卡顿且放大闪存损耗，应改按 id 单条 `put/delete`。IDB 无版本迁移框架。

**PWA 预缓存清单陈旧**：`sw.js` 的 SHELL 清单缺 8 个专题数据文件 + `node-lod.js`，用户首次**离线**打开未访问过的专题会地图空白；缓存版本号 `trace-v13` 硬编码需手工 bump。

## P2 · 体验与可访问性打磨

- **空态引导错位**：无数据时首页主 CTA 是「开始探索 → 景点地图」，而「怎么记第一篇」没打到首要位置；带插画的空态 `tripEmpty` 写了却从不展示（死代码）。
- **随手记强依赖定位**：`index.html:430` 定位被拒就只剩一句 toast，无「手动选点」兜底。
- **「AI 润色」预期误导**：引导说「AI 会帮你润色」，但润色/讲解/年报才需要 DeepSeek Key，录完点「整理一下」才被弹进 `sk-` 输入框；应加「不填也能直接保存原文」出口。
- **触控目标普遍 <44px**：返回键/顶栏动作/日历翻月 34px，标签 8px、元信息 10.5px、`--color-faint` 对比度仅 2.3:1（不达 WCAG AA）。至少把高频操作热区抬到 ≥44px（透明 padding 即可）。
- **底部悬浮件未处理安全区**：`.bottom-nav`/`.sheet`/`.savebar` 都没加 `env(safe-area-inset-bottom)`，iPhone Home 指示条会遮挡。
- **设置页持久化模型不一致**：`settings.html:387-395` 只保存 key/model/vad，而开关即时写、字号即时写——用户填了 Key 没点「保存设置」就返回会丢 Key。
- **按钮文案与落点对不上**：首页「海报与年报」`results.js:464` 实际跳 `review.html`；根目录 `workshop.html` 已不存在，但旧认知残留。

## 建议先做的 3 件事（收益最大）

1. **修 P0 的 5 个功能 bug**（网页语音、深色缩放按钮、断网搜索、首启引导合并、node-manager 模型名）——都是小改动，但都是用户「撞上就懵」的点。
2. **收口令牌 + 统一 `esc` + 统一 AI 调用**：删掉二次 `:root{}` 和重复变量；`esc` 全字符转义并套到自定义节点链路；DeepSeek 调用抽一个 `Ai.chat()`。一次解决漂移、重复、和一个 XSS 面。
3. **全国地图按省懒加载**：停止加载 3MB `nation-data.js`，复用分省文件。全国首屏直接减掉 ~3MB。
