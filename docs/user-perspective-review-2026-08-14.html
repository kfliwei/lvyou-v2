01 一句话结论

这是一款"内容与审美远超平均、但把用户当成了开发者"的产品：3362+ 节点、7782 索引、心愿单闭环、足迹海报都做得扎实；然而录音核心功能网页版不可用、AI 功能要用户自备 API Key、设置页一半是开发黑话——普通用户会在"记录"这一步流失。给普通用户打分，比专家评审低 1~1.5 分，差距全在"门槛"上。

03 用户旅程推演：7 个真实场景

以下按普通用户真实行为走一遍，标注每步"能不能走通、卡在哪"。

Step 1 · 发现

打开 App，找地方玩

首屏是品牌 hero + 大标题"今天，去哪里？" + 搜索框 + 时令推荐 + 8 个专题故事。专题故事化包装（红军长征/青藏风光/山西古建）有情感吸引力。

⚠ 卡点：首屏一半是品牌美学，功能入口在折叠线下；新用户要滚动 2~3 屏才见到「最近的旅行」和专题列表。首页搜索只搜"我的游记 + 专题"，全库搜索藏在面板里一个小链接——用户输"九寨沟"若自己的游记里没有，会以为产品没这个景点。
Step 2 · 规划

把想去的地方存起来

专题地图/全国地图点开景点详情 → 点「♡ 想去」→ 进心愿单。心愿单支持列表/地图双视图、跨省行程规划（按地理邻近自动分日、可调每天站数与公里上限）、一键导出 GPX。

✓ 走通：收藏入口在三个决策点都有（详情/首页/探索页），空状态有引导文案，闭环完整。
⚠ 卡点："导出 GPX"——普通用户不知道 GPX 是什么、导出给谁用（这是户外导航软件的格式，普通游客用不上）；规划结果只有文字列表，没有路线地图预览，用户无法直观判断"这计划顺不顺路"。
Step 3 · 到达

到了现场，打开看看

景点详情支持听讲解、高德导航衔接、离线地图（下载后断网可用，全国概览约 25MB）。

⚠ 卡点：讲解依赖 AI（需 API Key，无 Key 时行为不明确）；离线地图入口埋在设置页最底部，普通用户不会主动去下载，旅行途中才想起时往往已无网。
Step 4 · 记录 ⭐ 最大卡点

"到了，说两句"——产品的主卖点

首页底部「🎙 随手记」、详情页「语音记录」、心愿单「打卡后记录」，三条路径都通向语音游记。识别后可用 AI「整理一下」润色成文。

✓ 有降级：网页版 https 部署时走 Web Speech API（SpeechRecognition），实时转写、可编辑、文字随游记保存——不是完全不可用。
⚠ 剩余卡点：① 网页版无音频留存（录音文件回放依赖 APK 壳内引擎回调，浏览器环境拿不到音频流）；本地 file:// 打开时 Web Speech 不可用，会提示装 App；② AI 整理/讲解需要用户自备 DeepSeek API Key，普通用户不知道 sk- 是什么、去哪申请、要充值，无 Key 时按钮行为无引导。
⚠ 诊断文案误导：设置页语音诊断写「网页版不支持录音」，与代码实际能力（Web Speech 降级可用）不符，文案应改为「网页版仅支持浏览器语音转写，录音留存需 App」。
Step 5 · 回顾

回家后，看看自己走过哪

足迹地图（轨迹连线）、旅程叙事时间线（地图+卡片联动）、回顾页（月历热力、省份徽章、统计、AI 年度报告）。

✓ 走通：这是情感峰值环节，成就徽章（31 省）、热力日历、时间线重走旅程，收集感和仪式感都到位。
Step 6 · 分享

发朋友圈

足迹海报三款：竖版 / 横版（微信友好）/ 制图风（Stamen 主题），另有 AI 年报。

✓ 走通：横版 16:9 是刚需，制图风海报有差异化卖相。小卡点：入口叫「成果工坊」，普通用户不知道这词指什么（以为是成就兑换）。
Step 7 · 数据安全

换手机了，我的游记呢？

全部数据在本地（localStorage/IndexedDB），无账号无云同步；设置页有导出/导入备份、导出 Obsidian 库。

⚠ 卡点：普通用户没有备份习惯，换机/清缓存=全部游记丢失；「导出 Obsidian 库」对不知道 Obsidian 的用户是纯黑话。数据安全底线缺失。

04 实用性：真需求 vs 开发自嗨

真需求 · 强

全国景点库

34 省数据、7782 条索引、必去/网红分级——旅行决策刚需，覆盖度远超同类个人项目。

真需求 · 强

心愿单打卡闭环

想去→到达→打卡→记录，把"收藏"变成"去过"，情感链路完整。

真需求 · 强

足迹海报/年报

分享是旅行产品的增长引擎，三款海报已就位。

需求真 · 门槛高

语音记录 + AI 整理

场景真实（旅途口述比打字自然），但网页版不可录音 + 需自备 Key，普通用户触达不到。

需求真 · 门槛高

离线地图

旅行刚需，但入口太深、下载时机无法提前教育，实际使用率会很低。

开发自嗨

GPX 导出 / Obsidian 导出 / 节点管理

面向户外玩家和笔记工具党的功能，普通游客不认识 GPX、Obsidian、节点。占用了设置页一半空间。

开发自嗨

LOD 分层分级设置

"展开速度/聚合密度/必去优先"对普通用户是不可理解的工程参数，误触会得到"地图为什么变少了"的困惑。

潜力 · 未闭环

AI 讲解 / AI 生成节点介绍

概念好，但同样被 Key 卡住；且讲解无进度条/语速控制，长内容体验粗糙。

维度评价
视觉体系米白纸感 + 陶土橙 + 宋体标题 + 印章元素，全站一致，情感浓度高——普通用户第一眼"高级感"过关

07 改进优先级（普通用户视角）

优先级动作预期收益
P0AI Key 教程化/无 Key 置灰；录音补 MediaRecorder 音频留存 + 修正诊断文案把"记录"主链路对普通用户打开，是流失率最高的环节
P0数据备份傻瓜化（首次记录提醒 + 一键导出）数据安全感是留存底线
P1搜索合一（首页聚焦即全库）消除"内容少"的误判，搜索是内容产品第一入口
P1设置页"高级设置"收拢黑话项 + 人话说明普通用户不再被吓退，开发者功能保留但隐身
P1离线地图入口前置 + 下载引导把刚需功能送到用户手边
P2行程规划地图预览；海报/年报入口改名；字号三档体验打磨，提升口碑细节
一句话总结：产品内容与审美是 9 分级，但对普通用户的可达性只有 6.5 分——语音和 AI 两大卖点都卡在"用户搞不定"的门槛上。先把 P0 两个门槛拆掉，普通用户评分能立刻拉到 8 分；其余是锦上添花。
