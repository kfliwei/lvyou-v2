04做得好的地方（保留）

架构

数据驱动专题引擎

topic-meta.js 注册表 + topic-common.js 通用引擎，新增省份 = 数据文件 + 注册一条 + 入口卡片，不复制页面。12 省已跑通，这是全项目最值钱的架构决策。

数据

代码生成器 + 校验

tools/gen-nation.js 自动生成 nation-data.js，_verify-nation.js 做校验，数据与手写代码分离，避免 3362 个节点手工维护出错。

离线

PWA 分层缓存

shell 预缓存 + 数据文件 stale-while-revalidate + 导航网络优先断网回退，缓存版本号管理清晰（trace-v6），加失败容错（逐条 add + catch）。

topic-common.js：toggleTrip 勾选景点、drawTripRoute 按序画线、localStorage 按专题持久化行程、导航衔接。用户确认已满足需求。

results.js shareCanvas 生成分享长图；review.html 省份热力、月历热力、足迹统计齐备。海报基础能力已具备。

07UI/UX 提升建议

地图

节点聚合 + 省份 chips 分组

zoom<7 用聚合气泡代替全隐藏；12+ 省 chips 平铺横向滚动（34 省必失控）改区域分组折叠（华北/西北/西南…）。

详情

详情 sheet 动作条

固定底部动作：导航（高德 URI scheme）/ 收藏想去（配合心愿单）/ 生成分享卡 / 记录到此一游。当前只有「添加到行程」，闭环不全。

视觉

专题差异化封面

每省派生主色调 + 封面图（注册表已有色值，art/ 已有 8 张专题 SVG），打破 12 专题同模板的视觉疲劳。

性能

加载骨架屏

数据 + 瓦片加载期显示骨架/进度，避免白屏；SW 缓存命中后自然消失。

导航

底部导航 5 Tab

回顾页从设置页上位到主导航「探索/地图/旅途/回顾/我的」。

首页

时令推荐模块

hero 下方按月份推荐当季目的地，让首页从静态杂志变成活入口。

Phase 1 · 架构加固（第 1~30 天）

  • 想去清单 + 打卡转化闭环，与语音游记打通

  • 底部导航 5 Tab（回顾页上位）
Phase 3 · 体验深化（第 61~90 天）

从「记录工具」到「旅行伴侣」

  • 离线瓦片包 + 全国地图节点聚合
  • 专题差异化视觉 + 时令推荐
