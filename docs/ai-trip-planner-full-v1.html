Product Blueprint · v1 · 2026-08-15

对话式智能行程规划 · 完整方案

自然语言 → 真实数据 → 可执行行程 ｜ AI 管"选什么、为什么"，引擎管"怎么走、多久"

1. 产品定义

一句话定位：用户用一句话描述目的地/天数/喜好（喜好可不填），App 返回真实可执行的每日行程——候选是真实坐标节点，时间由算法实算，AI 负责推荐与叙事。
与聊天 AI 的差异：聊天 AI 给"文字方案"（可能幻觉、不可落地）；我们给"可执行对象"（真实坐标、地图轨迹、可保存可导航可打卡）。

2. 端到端用户流程

① 输入一句话：目的地+天数+偏好+出发地
② 解析AI 结构化为意图对象（可改可确认）
③ 召回三级数据源候选卡片列表
④ 筛选用户勾选加减，实时汇总
⑤ 排期引擎 2-opt + 时间模型出每日安排
⑥ 叙事AI 生成行程故事与每日主题
⑦ 产出地图轨迹/保存/分享/导航
⑧ 调整"D2 太赶了" → 引擎重排

3. 意图解析（对话层）

意图字段解析方式示例
目的地AI 抽取 + 本地城市/省份词典兜底（省/市/区域名 → 坐标圈）"西双版纳周边+广西" → [{region:'西双版纳', radius:'周边'},{province:'广西'}]
天数正则（N 天/N 日）6
偏好AI 映射到主题标签（自然风光→森林山川/江河湖泊/草原…）[自然] → 主题权重
出发地城市名 → 坐标；缺省=当前位置昆明
解析确认解析结果卡片展示，用户可改（下拉/输入）—

4. 三级数据源召回

级别来源召回策略字段完整度
一级本地库 7833 节点区域匹配（region/city/county）或 距目的地中心 < 圈选半径（周边=120km，省=全省）全字段
二级高德 POI（按需）本地库不足时按目的地城市+类型检索 top 20，标"临时点"（不污染本地库）名称/坐标/类型/照片
三级用户自建userNodes 全量参与用户定义
去重：名称相似 或 距离<500m 合并。排序：偏好主题命中 > 必去 > 网红 > 距出发地近。沉淀：行程中被收藏/打卡的临时点可一键回写本地库（众包扩库）。

5. 时间模型（引擎核心，AI 不碰数字）

组成计算默认值
路程段间 haversine 距离 ÷ 路型系数默认 60km/h；山区县/海拔差>800m → 40；用户可标"高速多"→ 90
游玩Σ 节点 playHours（节点新增字段，缺省 AI 建议+可改）自然 3h / 人文 2h / 美食 1h
休息每段 0.5h—
吃饭早 0.5 + 午 1 + 晚 1（当日含出发/返程日自动调整）—
每日上限驾驶 ≤5h，总时长 ≤12h（用户可调）—
排期算法：2-opt 优化（多起点对比，起点=出发地最优）＋ 地理聚类（同城/同县优先，避免 zigzag）＋ 双约束（时间为主、站数为辅）。校验：AI 生成初稿后引擎复核耗时，超限自动提示"该日预计 13h，建议减 1-2 站"并给出候选替换。

6. 数据模型

节点：现有字段 + playHours（新增，游玩时长，缺省由 AI 建议）
行程：{ id, name, createdAt, startPlace, days:[{ day, stops:[{ siteId|poiId, name, lat, lng, playH }], driveKm, driveH, playH, totalH, theme }], narrative }
临时点：{ src:'poi'|'user', id, name, lat, lng, type, photo }——不入本地库，行程内引用

7. UI 流程（行程规划页改造）

阶段界面交互
对话输入规划页顶部对话条"✍️ 告诉我你想怎么玩…"支持自然语言 + 快捷标签（天数/偏好 chips）
解析确认意图卡（目的地/天数/偏好/出发地）可逐项修改
候选列表景点卡片（图/名/类型/建议时长/必去网红徽标/临时点标识）勾选/取消，底部汇总条"已选 12 个 · 预计 5 天"实时更新
排期结果每日卡片（地图轨迹缩略 + 站列表 + 各耗时）点轨迹看地图色线；↑↓/移除/换点
AI 叙事行程一句话故事 + 每日主题一键复制分享
行程库已保存行程列表（命名/日期/分享/删除）复用现有保存机制
多轮调整快捷对话（"D2 太赶了"/"换成小众的"）引擎重排/换候选

8. 里程碑

里程碑内容工作量
M1对话入口 + 意图解析（AI+规则兜底） + 本地库召回 + 候选勾选 + 引擎排期（2-opt+时间模型） + 地图轨迹 + AI 叙事 + 保存/分享1-1.5 天
M2高德 POI 补位（临时点）+ 多轮调整对话 + playHours 批量建议1 天
M3行程库管理增强 + 导航串联（每日逐站导航）+ 临时点回写本地库1 天
M4（可选）天气/路况联动（雨天自动提示室内点）、团队分享行程按需

9. 风险与对策

风险对策
意图解析不准本地词典规则兜底 + 解析结果卡可改
时间估算误差系数可调 + 标注"估算" + 按用户反馈修正默认系数
AI 幻觉（数字/地点）引擎覆盖全部数字；AI 只产出叙事文本；无数据源地点明确提示
高德/DeepSeek Key 依赖高德来源校验（用户在控制台已修）；DeepSeek Key 已有；均降级可用（无 AI 时引擎+本地规则仍能走通全流程）
候选过多/过少圈选半径自适应（候选 <8 扩大，>40 缩小）；偏好权重调节
