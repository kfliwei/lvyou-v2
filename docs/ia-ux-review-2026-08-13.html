合理之处（保留）

项评价

问题清单（按优先级）

级别问题现状与影响建议
P1两套全国地图并存nation-map.html（老独立页，仅首页入口，自带 LOD/详情实现）与 topic.html?p=nation（统一引擎，探索页入口）功能重复、交互细节两套实现，维护与体验成本双高合并：nation-map.html 迁移到统一引擎（其独有能力：离线瓦片/半径查询/骨架屏并入 topic-common 引擎），全站只留一个全国入口
P1"我的"Tab 实为设置页无任何个性化内容（成就/足迹/收藏摘要全在别处），用户打开"我的"看到的是 AI Key 和诊断项——身份感缺失"我的"改为「我的足迹」主页：成就徽章（已实现，从回顾搬来）、足迹摘要卡、心愿单入口、最近游记；设置降级为页内次级入口
P2旅程叙事（story）埋没story 入口只在设置页，用户几乎不可能发现；与回顾页同属"旅程回顾"域回顾 Tab 内做视图切换（回顾 / 叙事 / 月份），或 story 并入回顾页为「时间线」视图
P2搜索两套逻辑首页搜索（游记+专题）与 search.html（全库）并存，入口两处、结果范围不同统一：首页搜索框聚焦即跳 search.html（全库），删除首页内嵌双组逻辑或保留为快捷入口
P2"地图"Tab 语义偏差Tab 名"地图"指向个人游记地图，用户会以为能打开全国/专题地图改名「足迹」（个人数据语义）或调整 Tab 结构：探索 / 地图（全国）/ 记录 / 回顾 / 我的
P3探索页职责稍重专题卡 + 搜索 + 心愿单 + 语音引导四类内容一页可接受；搜索与心愿单入口保留即可，不必拆分

03 UI/UX 设计评估

强项（保持）

维度评价
视觉体系米白纸感 + 陶土橙 + 宋体标题 + 印章元素，全站一致性强，是同类产品里少有的完整设计语言
状态设计骨架屏、空态插画、加载失败提示三态齐全；两档字号自适应、深色模式、必去/网红视觉分级均已落地
地图交互LOD 分级聚合、聚合胶囊、半径查询、路线绘制、导航衔接——移动端地图体验完成度高
触控规范底部导航 76px 高、按钮 ≥44px、间距 8pt 体系，符合移动端标准

改进建议

详情 Sheet 动作收纳

当前动作行 6 项（听讲解/语音记录/加入行程/想去/地图查看/收起），窄屏易拥挤（此前有 revert 记录）。建议主操作保留 2 个（听讲解/语音记录），其余收进「更多」展开。

图标体系统一

导航/控件已用统一 SVG 线性图标，但部分动作按钮用 emoji（🎙 听讲解、💡 提示），与品牌调性有落差。建议关键操作图标 SVG 化。

首页首屏密度

hero 品牌区 + 搜索占首屏大半，专题入口在折叠线下。建议 hero 压缩 1/3，让「我的旅程」与专题入口上移。

无障碍补强

已有 focus-visible 与减弱动效支持；补 aria-label（图标按钮）、语音结果大字模式、触控目标 44px 复核。

交互一致性

专题页与全国页详情实现两套（合并全国地图后自然统一）；「想去的」按钮在专题/全国两处的反馈文案需一致。

导航活跃态

底部 Tab 活跃态只体现在当前页；建议跨页保持（专题页停留时"探索"仍高亮）。

04 优先级路线

优先级动作价值
P1全国地图合并到统一引擎（删重复实现）消除重复维护 + 交互统一，省后续每个功能双倍工作量
P1"我的"改造成足迹主页（成就/摘要/入口 + 设置次级）补齐身份感，成就体系有归属地，留存提升
P2story 并入回顾 Tab 视图切换内容发现率提升
P2搜索统一到全库搜索页一套逻辑，行为一致
P3详情 Sheet 收纳 / 图标 SVG 化 / 无障碍补强打磨细节，提升质感
一句话总结：信息架构骨架正确、视觉体系优秀；当前最大问题不是"设计"而是"重复与归属"——两套全国地图、成就无处安放、叙事被埋没。优先做「合并全国地图 + 我的页改造」两件事，IA 就能从 8.2 到 9 分。
